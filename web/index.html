Review multiline paste

Newlines may execute commands. Verify every line before sending. This review applies even when bracketed paste is enabled; terminal modes can change.

The preview displays CR, LF and CRLF as line breaks. The original clipboard text is shown below as a quoted string: \r means carriage return, \n means line feed, \t means tab and \\ means a literal backslash. Unicode format characters, including bidirectional controls and zero-width joiners, appear as \uXXXX escapes (two escapes for a supplementary character); this does not remove them from the paste. Other characters remain literal, so this is not a complete code-point listing. On delivery, each CRLF pair, lone CR or LF becomes one carriage return. Bracketed paste markers depend on the terminal mode at delivery.

Local file preview (experimental)
This opt-in preview reads only files selected below. Ctrl+left-click an exact visible relative file name to select it, then confirm Preview selected file. The confirmation is required because terminal output cannot prove a local or remote identity. Positive :line or :line:column suffixes select the same file (no line navigation). Wrapped paths, absolute paths and OSC 8 links are not resolved. Markdown, TSX, HTML and SVG are plain source text, never executed. Static PNG and baseline JPEG are limited to 2 MiB, 4096 per side and 4 megapixels. Other image formats are not decoded. Re-select the folder to refresh its snapshot.
