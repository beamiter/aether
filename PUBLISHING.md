# Aether source import

This repository imports the v19 Tauri 2 terminal laboratory checkpoint.
The imported shared core was pinned to `2b37583ab1a833176e88145e67243146f99c309a`.
This is an experimental prototype, not a daily-use terminal or a completed five-host validation.

Source, lockfiles, tests, examples, frontend fixtures and checkpoint documentation are preserved.
Machine-specific dependency helpers, raw build/test logs and generated Tauri schemas are excluded from this public source distribution. Historical documents referencing raw logs refer to the original checkpoint archive.

The v19 checkpoint recorded 127 tests, strict Clippy, Linux debug build and real Vim PTY smoke passing. These historical results do not constitute new GitHub CI or GUI validation. Native WebKit GUI, pixels, Wayland and platform IME remain unvalidated.

The current maintained pin and validation commands are in README.md. Historical checkpoint records are not the current CI result.
